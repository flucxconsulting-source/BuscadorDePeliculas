# Prompt 01 — Preparar proyecto

Actúa como estudiante principiante de Android Kotlin. Revisa primero el proyecto existente y conserva su package, configuración y versiones compatibles. No recrees el proyecto.

Prepara exactamente dos Activities: MainActivity (inicio) y DetailActivity. Usa Kotlin para lógica y XML para vistas, con findViewById; no uses Java, Compose, ViewModel ni arquitectura avanzada. Añade solo las dependencias que falten: Retrofit, Gson converter, RecyclerView y Picasso. Configura permiso INTERNET en AndroidManifest.xml y registra DetailActivity.

No implementes todavía la búsqueda ni los layouts completos. Sincroniza Gradle y comprueba compilación. Corrige solo errores de esta fase. Resume cambios, realiza commit y push si compila y no hay secretos. Si no compila, explica por qué. Detente y espera el prompt 02.
